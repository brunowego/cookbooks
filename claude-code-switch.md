# Claude Code Switch (CCS)

**Keywords:** Claude Code Multi-Account Switcher

## CLI

### Installation

```sh
# Using NPM
npm install -g @dingpx/claude-code-switch
```

### Commands

```sh
ccs -h
```

### Usage

```sh
#
ccs current
ccs now

#
ccs list

#
ccs switch

#
ccs switch production
ccs use development

#
ccs open
```
