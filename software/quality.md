# Software Quality

## Glossary

- Minimal Quality Acceptable (MQA)

## Good Naming Matters

- Code explains itself
- Clear names prevent mistakes
- Issues are easier to spot
- Others understand your code faster
- Future you will thank you
- Enhancing scalability… Refactoring is smoother
- Minimizing redundant comments… Less need for extra explanations

## Standards

- camelCase: userName, calculateTotal()
- snake_case: user_name, calculate_total()
- PascalCase: UserManager, OrderService
- dash-case:
- UPPER_CASE: MAX_RETRIES, DEFAULT_TIMEOUT
- Boolean names: isValid, hasAccess, canDelete
- Function names: fetchData(), sendEmail()
- Class names: UserController, InvoiceProcessor
- Avoid abbreviations: userCount, not uc
- Be consistent with language conventions
