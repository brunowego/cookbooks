## CLI

### Installation

```sh
# Using Homebrew
brew install openapi-generator

# Using Scoop
scoop install openapi-generator-cli
```

### Commands

```sh
openapi-generator -h
```

### Usage

```sh
#
openapi-generator generate \
  -i <filename>.yml \
  -g go \
  -o ./<foldername>
```
