# cavemem

## Links

- [Code Repository](https://github.com/JuliusBrussee/cavemem)

## CLI

### Installation

```sh
# Using NPM
npm install -g cavemem
```

### Commands

```sh
cavemem -h
```

### Initialize

```sh
cavemem install
```

### Usage

```sh
#
cavemem status

#
cavemem viewer

#
cavemem doctor
```
