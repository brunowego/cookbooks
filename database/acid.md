# Atomicity, Consistency, Isolation, Durability (ACID)

**Keywords:** RDBMS

![ACID Diagram](/assets/images/acid-diagram.webp)

## Glossary

- Atomicity: A transaction is an atomic unit of work that either succeeds or fails as a whole.
- Consistency: A transaction must bring the database from one valid state to another.
- Isolation: A transaction must operate on a consistent view of the database.
- Durability: A transaction must ensure that the changes are permanent and will not be lost.
