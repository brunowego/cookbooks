# uv

## Links

- [Code Repository](https://github.com/astral-sh/uv)
- [Docs](https://docs.astral.sh/uv)

## CLI

### Installation

```sh
# Using Homebrew
brew install uv
```

### Commands

```sh
uv -h
```

### Usage

```sh
#
uv python list

#
uv python install <version>

#
uv venv
source ./.venv/bin/activate

#
uv pip install -r ./requirements.txt

#
uv run python <script>
```
