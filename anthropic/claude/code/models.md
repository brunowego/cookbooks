# Models

## Features

| Feature                     | **Opus**                                   | **Sonnet**                                 | **Haiku**                              |
| --------------------------- | ------------------------------------------ | ------------------------------------------ | -------------------------------------- |
| **Intelligence**            | Highest                                    | High                                       | Good                                   |
| **Speed**                   | Slowest                                    | Medium                                     | Fastest                                |
| **Cost**                    | Most expensive                             | Moderate                                   | Cheapest                               |
| **Best for**                | Complex reasoning, research, agentic tasks | Everyday coding, writing, analysis         | Classification, extraction, routing    |
| **Context handling**        | Deep, nuanced                              | Strong                                     | Adequate                               |
| **Code tasks**              | Architecture, deep reviews, hard bugs      | Daily development, refactoring, generation | Simple generation, linting suggestions |
| **Writing**                 | Long-form, subtle, creative                | Professional, versatile                    | Summaries, short responses             |
| **Multi-step planning**     | Excellent                                  | Good                                       | Limited                                |
| **High-volume / real-time** | Overkill                                   | Viable                                     | Ideal                                  |
| **Sweet spot**              | "I need the best answer"                   | "I need a great answer, fast"              | "I need a good-enough answer, now"     |
