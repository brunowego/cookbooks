# Retrieval-Augmented Generation (RAG)

## Stack

- LLM: GPT-4, Claude, Mistral etc.
- Vector DB: Qdrant, Weaviate, Pinecone, Chroma
- Embeddings: text-embedding-3-small, all-MiniLM-L6-v2, etc.
- Orchestration: LangChain or LlamaIndex
- Data source: PDFs, SQL databases, websites, Markdown files etc.
