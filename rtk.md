## Installation

```sh
# Using Homebrew
brew install rtk
```

### Commands

```sh
rtk -h
```

### Initialization

```sh
rtk init -g
```

### Configuration

```sh
# Disable telemetry
rtk telemetry disable
```

### Usage

```sh
#
rtk gain
```
