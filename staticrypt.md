# StatiCrypt

**Keywords:** Static HTML Page Password Protect

## Links

- [Code Repository](https://github.com/robinmoisson/staticrypt)
- [Main Website](https://robinmoisson.github.io/staticrypt)

## Library

### Installation

```sh
# Using pnpm
pnpm add staticrypt -D
```

### Configuration

```sh
echo '/.staticrypt.json' >> ./.gitignore
```

## CLI

### Commands

```sh
npx staticrypt -h
```

### Usage

```sh
#
npx staticrypt -r ./dist
```
