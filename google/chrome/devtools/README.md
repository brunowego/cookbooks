## Tips

### Filter Network Requests

- `domain:<domain>` (e.g. `domain:google.com`)
- `method:<method>` (e.g. `method:GET`)
- `status-code:<code>` (e.g. `status-code:200`)
- `larger-than:<size>` (e.g. `larger-than:1k`)
- `mime-type:<type>` (e.g. `mime-type:image/jpeg`)
- `has-response-header:<header>` (e.g. `has-response-header:content-type`)
- `is:<text>` (e.g. `is:running`)

**Note**: You can combine filters using `AND` and `OR` operators. You can also use `-` to exclude results.
