# Claude Code Switch (CCS)

## Links

- [Code Repository](https://github.com/kaitranntt/ccs)
- [Main Website](https://ccs.kaitran.ca)

## CLI

### Installation

```sh
# Using NPM
npm install -g @kaitranntt/ccs
```

### Commands

```sh
ccs -h
```

### Configuration

```sh
#
ccs config

#
ccs doctor
```

### Usage

```sh
#
ccs auth create <name>

#
ccs sync

#
ccs update
```
