# Domains

## Tips

### Transfer Domains

#### From Godaddy

1. [Products](https://account.godaddy.com/products)
2. Domains -> Select one -> Manage
3. Manage Domain -> Domain Configuration
4. General Tab -> Transfer -> Domain Lock -> Unlock and Transfer to another registrar
5. Transfer to another registrar -> Continue -> Get Authorization Code
6. Go to Cloudflare -> [Add site](https://dash.cloudflare.com/?to=/:account/add-site)
7. Enter an existing domain -> Continue
