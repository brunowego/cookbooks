# Cursor Agent

## Links

- [Cursor Agent CLI](https://cursor.com/blog/cli)

## CLI

### Installation

```sh
#
curl https://cursor.com/install -fsSL | bash
```

### Environment

For Bash or Zsh, put something like this in your `$HOME/.bashrc` or `$HOME/.zshenv`:

```sh
# Local Binary Path
export PATH="$HOME/.local/bin:$PATH"
```

```sh
source ~/.zshrc
```

### Commands

```sh
#
cursor-agent -h
```

### Usage

```sh
#
cursor-agent
```
