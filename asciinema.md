# asciinema

## Links

- [Main Website](https://asciinema.org)

## CLI

### Installation

```sh
# Using Homebrew
brew install asciinema

# Using YUM
yum check-update
sudo yum -y install asciinema

# Using APT
sudo apt update
sudo apt -y install asciinema
```

### Commands

```sh
asciinema -h
```

### Configuration

```sh
#
asciinema auth
```

### Usage

```sh
#
asciinema rec

#
asciinema play ./<filename>.cast
```
